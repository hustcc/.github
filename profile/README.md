<p align="center">让中文 Markdown 写作更规范、更一致。</p>

<p align="center">Lint your Chinese Markdown for cleaner, more consistent writing.</p>

lint-md 是一组围绕中文 Markdown 写作规范的开源工具集合，基于 AST 实现检查与自动修复能力，覆盖命令行、Node.js API、编辑器插件与 CI 集成等多种使用场景。

## 项目

- [`lint-md/lint-md`](https://github.com/lint-md/lint-md)：主仓库与能力集合
- [`lint-md/cli`](https://github.com/lint-md/cli)：命令行工具
- [`lint-md/parser`](https://github.com/lint-md/parser)：基于 remark 生态的 Markdown 解析器
- [`lint-md/prettier-plugin`](https://github.com/lint-md/prettier-plugin)：Prettier 插件
- [`lint-md/eslint-plugin`](https://github.com/lint-md/eslint-plugin)：ESLint 插件
- [`lint-md/github-action`](https://github.com/lint-md/github-action)：GitHub Action 集成
- [`lint-md/vscode-plugin`](https://github.com/lint-md/vscode-plugin)：VS Code 插件
